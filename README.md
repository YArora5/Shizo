# 🤖 SHIZO

### A small AI-powered interactive device with a personality.

> **SHIZO is a personal hardware project I'm building to explore what happens when AI, electronics and a little personality come together in one small device.**

---

## 🧠 What is SHIZO?

SHIZO started with a simple idea:

**What if an AI assistant wasn't just a chat window?**

Instead of interacting with AI only through a phone or laptop, I wanted to build a small physical device that could **look alive, react to the user, show emotions and eventually talk back.**

SHIZO is being developed around an ESP-based controller, a small OLED display, Wi-Fi communication and a web interface.

The project is still under development, so I'm building and testing each part step by step.

## 🖥️ What SHIZO Can Do Right Now

The current version can start its own Wi-Fi network and provide a small web interface that can be accessed from a phone or laptop.

The device can:

- Start a Wi-Fi access point
- Host a local web interface
- Receive user input
- Change its displayed emotion
- Display different facial expressions
- Communicate between the ESP device and the web interface
- Handle basic device states and behaviour

The goal is to keep improving this foundation instead of trying to build everything at once.
